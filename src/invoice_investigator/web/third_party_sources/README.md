# Liberation Fonts 1.07.4 source

`liberation-fonts-1.07.4.tar.gz` is the complete, unchanged source archive from
[the upstream release](https://releases.pagure.org/liberation-fonts/liberation-fonts-1.07.4.tar.gz),
linked by the [Liberation Fonts project](https://github.com/liberationfonts/liberation-fonts).

SHA-256:
`ad98b7498dc2992f7f0868f79b65ce4a720a3acdb63ab3f1f1cb6881117a5406`

The archive includes 16 editable SFD fonts, `Makefile`, conversion/build scripts,
`README`, `AUTHORS`, `License.txt` and `COPYING`. Its README describes building
with FontForge and the Makefile. No font build is required to run this demo.

This source accompanies the four Liberation Sans TTF files shipped unchanged
from PDF.js 6.4.299. [PDF.js's versioned font documentation](https://github.com/mozilla/pdf.js/blob/v6.4.299/external/standard_fonts/README.md)
and [maintainer verification](https://github.com/mozilla/pdf.js/pull/21750)
identify version 1.07.4. Their GPL-2 license and Liberation exceptions remain at
`../static/review/vendor/pdfjs/standard_fonts/LICENSE_LIBERATION`.

The source archive is included in both the application wheel and source
distribution. It is licensing material, not an application runtime component.
