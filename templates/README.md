# Reusable Activity Templates

These three files are intentionally unfilled source templates from
dev-to-prod-workflow commit 70652f67cbc61a2d76d8a2ba9284d6e6b8b42279:

- [Current activity plan](PLAN.current-activity.md): copy to local PLAN.md only
  for the next reviewed activity.
- [Adoption preflight](template-adoption-preflight.local.md): copy to the local
  approval area when adopting or refreshing the workflow.
- [Issue ledger](production-readiness-issues.local.md): copy only when a
  multi-issue readiness review needs it.

Their prompts and blank fields are intentional; they are not completed project
plans or evidence. Filled copies remain local and excluded from releases.
These reusable engineering templates are also excluded from the customer
deployment ZIP.
